Нажмите **↑**, как в терминале, — но недописанный черновик останется в безопасности. `dsh-composer-history` переносит модель клавиш Claude Code «сначала курсор, потом история» в веб-композер dsh и идёт дальше: когда вы возвращаетесь к самой свежей записи (или жмёте `Esc`), сохранённый черновик и позиция курсора **восстанавливаются точно**, а не очищаются.

> Чистое UI-поведение: без новых событий сессии, без правок agent-loop, без запросов к модели. Вызванный текст попадает только в обычный черновик композера и достигает модели, лишь когда *вы* нажмёте Enter.

## ✨ Особенности

- 🎯 **Сначала края** — голые ↑/↓ сначала двигают курсор. Вызов истории срабатывает только когда курсор на первой/последней строке черновика.
- 💾 **Сохранение черновика** — первый вызов сохраняет `{draft, caret}`; возврат к самой свежей записи (или `Esc`) восстанавливает оба точно. Claude Code здесь очищает — мы восстанавливаем.
- 🛡️ **Защита от расхождения** — отредактировали вызванную запись — просмотр немедленно завершается, правка становится новым черновиком.
- 🔄 **Живая история** — извлекается из снимка сессии на каждое нажатие: сообщения `kind === 'user'`, текстовые блоки склеиваются, пустые пропускаются, соседние дубли сливаются, самая свежая запись в конце. Новые отправленные сообщения попадают автоматически.
- 🚦 **Полное гейтирование** — перехват только в фазе `plain`; уступает slash-меню, командным попапам, IME-композиции, выделению текста и комбинациям alt/meta/shift. Пути пропуска не имеют побочных эффектов.
- 📐 **Два режима краёв** — `logical` (по символам `\n`, по умолчанию) или `visual` (скрытый mirror-div измеряет реальные перенесённые строки).

## 🎬 Как это ощущается

```text
$ вы печатаете недописанный промпт и жмёте ↑
        └─ черновик сохранён, самая свежая запись заполняет композер
$ ↑ ↑ … к более старым записям      $ ↓ ↓ … назад к самой свежей
        └─ на самой старой: hold (перехват без изменений)   └─ ещё один ↓: ваш черновик на месте,
                                               курсор ровно там, где был
$ Esc в любой момент → мгновенное восстановление, просмотр завершён
```

## 📦 Установка

**Сначала соберите, потом запускайте** — проверка клиентских пакетов отказывается загружать несобранный бандл.

1. Соберите плагин (см. выше).
2. Зарегистрируйте строку в `$DSH_HOME/profiles/<профиль>/cordis.patch.yml`. В поле `name` указывайте **голое имя пакета**: id строки графа браузера — это ровно та строка, а клиентский бандл зашивает тот же id при сборке.

   ```yaml
   # добавляется после слоёв бандлов
   - insert:
       - id: composer-history
         name: dsh-composer-history
         config:
           recallWithDraft: save     # 'save' | 'gate'
           restoreOnEscape: true
           edgeMode: logical         # 'logical' | 'visual'
           enableCtrlAlias: true
           restoreCaret: true
   ```

3. Голые строки обязаны также присутствовать в манифесте-резолвере профиля — хост-Loader разрешает их из `node_modules` каталога профиля:

   `$DSH_HOME/profiles/<профиль>/package.json`:

   ```json
   {
     "name": "dsh-profile-<профиль>",
     "private": true,
     "dependencies": {
       "dsh-composer-history": "file:D:/deepseek-harness/Project/Plugins/dsh-composer-history"
     },
     "dsh": {
       "profile": {
         "bundles": ["@deepseek-ai/dsh-base", "@deepseek-ai/dsh-web-app"]
       }
     }
   }
   ```

4. `pnpm install` в каталоге профиля, затем:

   ```sh
   dsh --profile <профиль> --port 3080
   ```

## ⚙️ Config

Все настраиваемые параметры живут в Schemastery-схеме `Config` (никаких захардкоженных ручек). Недопустимые значения перечислений **громко роняют весь запуск dsh** — хост-Loader валидирует блок `config:` из cordis.yml той же схемой.

| Поле | Тип | По умолчанию | Смысл |
| --- | --- | --- | --- |
| `recallWithDraft` | `'save' \| 'gate'` | `'save'` | `save`: непустой черновик сохраняется перед вызовом; `gate`: вызов только при пустом черновике (гейт в духе Claude/Codex) |
| `restoreOnEscape` | `boolean` | `true` | `Esc` во время просмотра восстанавливает сохранённый черновик |
| `edgeMode` | `'logical' \| 'visual'` | `'logical'` | определение края по строкам `\n` или по измеренным перенесённым строкам |
| `enableCtrlAlias` | `boolean` | `true` | Ctrl+↑/↓ действует как голые стрелки |
| `restoreCaret` | `boolean` | `true` | возврат вниз/`Esc` также восстанавливает сохранённый курсор |

## 🎹 Раскладка клавиш

| Клавиша | Состояние | Поведение |
| --- | --- | --- |
| ↑ | IDLE, курсор на первой строке | сохранить {черновик, курсор}, вставить самую свежую запись, курсор в конец (нет истории → пропуск) |
| ↑ | BROWSING, курсор на первой строке | более старая запись; на самой старой — hold (перехват без изменений) |
| ↑ | курсор не на первой строке | полностью отпускается (браузер двигает курсор) |
| ↓ | IDLE | всегда отпускается (обычное движение курсора) |
| ↓ | BROWSING, курсор на последней строке | более новая запись; на самой свежей → восстановить `savedDraft` + `savedCaret` → IDLE |
| ↓ | курсор не на последней строке | полностью отпускается |
| Esc | BROWSING (`restoreOnEscape: true`) | восстановить `savedDraft` + `savedCaret` → IDLE, перехват |
| Esc | иначе | отпускается (семантика Esc меню/попапов не тронута) |
| Ctrl+↑/↓ | `enableCtrlAlias: true` | как голые стрелки |
| Shift/Alt/Meta+стрелки, IME, выделение | любое | всегда отпускается |

## ✅ Проверка

1. Откройте веб-интерфейс и убедитесь, что `window.__DSH_BOOT__` содержит строку плагина (`id: "dsh-composer-history"`, `url: "/plugins/dsh-composer-history/client.js?rev=…"`).
2. Запросите `/plugins/dsh-composer-history/client.js` — ожидается `200` (`text/javascript`).
3. Ручной чек-лист:
   - Пустой композер: ↑ вызывает последнее сообщение; ещё ↑ — к более старым; ↓↓ — назад к свежей; ещё ↓ — возврат к пустому.
   - Недописанный черновик: ↑ сохраняет и вызывает; ↓↓ до низа восстанавливает черновик **включая курсор**; `Esc` — мгновенное восстановление.
   - Многострочный черновик: в середине ↑/↓ только двигают курсор; вызов срабатывает лишь с первой/последней строки.
   - Вызов записи `/xxx` и Enter — команда проходит обычную арбитражную обработку (ожидаемо).
   - При открытом slash-меню ↑/↓ двигают только подсветку меню.
   - Во время генерации модели (фаза ≠ `plain`) стрелки не вызывают историю.
   - Shift+↑/↓-выделение, IME-композиция, Ctrl+Z/Y (undo/redo) не затронуты.
4. Гейты: `pnpm run typecheck`, `pnpm run build`, `pnpm run test` — всё зелёное, включая смоук-тест, выполняющий **собранный бандл** в jsdom через настоящее рукопожатие `__ModuleLoader__`.

## 🔬 Базовый уровень совместимости (замерено на этой машине, 2026-08-13)

- База: локальный чекаут `D:\deepseek-harness` (`lib/types` клиентских пакетов собраны 2026-08-13); клиентские пакеты **0.1.0-rc.5** (последняя версия на npm — 0.1.0-rc.6, rc.5 не опубликована); `@deepseek-ai/cordis` **4.0.1**; `@deepseek-ai/schemastery` **3.18.1**.
- Фазы `InputState` (прочитано из `packages/client/ui-conversation/src/client/input/contract.ts`): `'plain' | 'adjudicating' | 'claimed' | 'submitting'`, плюс `draft`/`draftRev`. Единственный путь записи черновика — `ctx.conversation.input.for(actx).setDraft(text)`.
- **Метаданные клиентских плагинов — вложенное поле `dsh.client`** (`resolveMeta` в `packages/client/modules` читает `pkg.dsh.client`): неверное расположение **молча** выбрасывает пакет из графа загрузки — без ошибок.
- **Вендоренный cordis переименован в `@deepseek-ai/cordis`**: импорт только type-only; замерено: в собранном `lib/client.js` нет runtime-импортов cordis (вообще нет вызовов `require(`).
- **Браузерная загрузка не передаёт плагинам config** (граф загрузки содержит только `{id, url, rev, inject, immediately}`): браузерная половина применяет дефолты схемы; блок `config:` в cordis.yml валидирует хост-Loader той же схемой. Замерено: `recallWithDraft: bogus` обрывает весь запуск — `failed to apply loader entry composer-history … $.recallWithDraft expected "save" | "gate" but got "bogus"`.
- **После правок исходников — пересборка до перезапуска**: стартовая проверка читает `lib/client.js`, несобранные пакеты отклоняются; браузер всегда получает только собранные артефакты.
- **Только экспортированные символы**: межпакетные чтения используют типы/сервисы из `/client`-входов пакетов `@deepseek-ai/dsh-client-*`; приведение сервиса `inputTriggers` к `InputTriggerService` — принятый в сообществе паттерн (здесь: type-only импорт + `ctx.get('inputTriggers') as InputTriggerService | undefined`, с поясняющим комментарием).
- Контракт клиентского бандла: CJS-фабрика, обёрнутая в `window.__ModuleLoader__.load({ id, factory })`, платформенные модули (react, cordis, slots и др. + исключение `@deepseek-ai/dsh-client-runtime/client`) — снаружи, остальное — внутрь. У этого плагина нет runtime-внешних зависимостей; конфиг tsdown объявляет список оборонительно.
- Тайпчек внешних плагинов: rc.5 нет на npm, поэтому tsconfig `paths` указывает на `packages/client/*/lib/types/client/index.d.ts` локального чекаута + `skipLibCheck`. После обновления чекаута перезапустите typecheck.
- Файлы профиля должны быть **в UTF-8 без BOM** (`readProfileManifest` делает простой `JSON.parse`; замерено: BOM даёт `Unexpected token '\uFEFF'` и падение запуска).

## ⚠️ Известные ограничения

- **Логические и визуальные строки**: по умолчанию `logical` смотрит на `\n` (длинное автоматически перенесённое сообщение считается одной строкой); `visual` измеряет реальные переносы через mirror (скрытый узел, бинарный поиск O(строк·log n) на каждую проверку края).
- **Только текущая сессия**: v1 вызывает историю из спроецированного окна текущей сессии — без межсессионной и дисковой истории. После перезагрузки страницы история сохраняется (проекция из лога сессии); состояние просмотра — нет.
- **Стек undo включает транзакции вызова**: каждая вставка/восстановление — это одна `setDraft`-транзакция в undo-логе машины ввода; Ctrl+Z может пошагово откатывать вызовы. Плагин не меняет семантику undo/redo.
- Вызов записи `/xxx` и Enter идёт по обычному пути claim/арбитража команд (ожидаемо; Enter никогда не перехватывается).
- Меню/попапы и фазы, отличные от `plain`, всегда приоритетны; очистка черновика после отправки (программная) и переключение сессий возвращают состояние в IDLE.
- Замер `visual`-mirror нельзя юнит-тестировать в jsdom (нет движка раскладки); чистая математика span-ов протестирована.
- Ссылочные чипы (плейсхолдеры U+FFFC) переносятся вместе с вызываемым/восстанавливаемым текстом черновика.
